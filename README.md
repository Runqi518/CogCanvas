# CogCanvas — 认知科学驱动的创造力画布

一个以无限画布为核心、内置认知科学触发机制的创意辅助工具。画布不仅是记录空间，更会主动提供打破思维定式的刺激。

## 视觉风格

**美拉德色系（Maillard）**：奶霜 / 燕麦 / 焦糖 / 摩卡 / 浓缩咖啡的暖色烘焙色板，配合暖阴影与纸张质感，营造"咖啡馆 + 手账"式的创作氛围。

## 技术栈

- React 18 + TypeScript + Vite
- [reactflow](https://reactflow.dev/) 画布引擎（节点/连线/缩放/拖拽，原生虚拟化）
- Zustand 状态管理
- Tailwind CSS
- IndexedDB（通过 `idb`）本地持久化，无需后端
- 纯前端 TF-IDF + 余弦相似度做语义聚类（对中文友好，无需分词/大模型）

## 运行

```bash
npm install

npm run build    # 生产构建（含 tsc 类型检查）

| `/canvas/:id` | 无限画布主页面（发散/收敛双模式） |
| `/workflow` | 创意工作流呈现页：5 步认知工作流 + 5 类触发卡 |

## 创意工作流（对齐 PRD）

```
发散记录 → 认知触发 → 语义聚类 → 收敛评估 → 精选导出
（双钻石：发散 × 3，收敛 × 2）
```

1. **发散记录**：无限画布外部化工作记忆，双击创建节点、拖拽连线，先发散不评判
2. **认知触发**：选中节点"抽卡"，5 类认知科学触发卡打破功能固着
3. **语义聚类**：TF-IDF 相似度分析，淡色块提示相近想法群，一键聚拢
4. **收敛评估**：切换收敛模式，打"可行性/主题"标签，看板自动分组
5. **精选导出**：勾选精选想法，一键导出 Markdown 交付

## 已实现的 MVP 功能

### 1. 无限画布（2.1）
- 双击空白处创建文本节点，自动进入编辑态
- 节点自由拖拽、缩放画布、平移、小地图导航
- 拖拽节点右侧圆点连线，连线自动带类型标签
- `Delete`/`Backspace` 删除选中节点/连线

### 2. 画布项目管理（2.5）
- 首页卡片式列表，含内容预览、节点数、最后编辑时间
- 新建 / 重命名 / 删除 / 复制
- 数据存于 IndexedDB，含 `schemaVersion` 便于未来迁移到云端

### 3. 认知触发器面板（2.2）—— 核心差异化
选中节点后右侧浮现面板，可抽取 5 类触发卡（每类 ≥20 条静态题库，位于 `src/data/triggerBank.ts`，便于替换为 LLM 生成）：

| 卡片 | 认知原理 | 行为 |
|------|----------|------|
| 🔗 强制关联 | Koestler 双联思维 | 随机不相关词，问"和它有什么关系？" |
| 🪜 抽象阶梯 | 抽象层级理论 | ↑更抽象 / ↓更具体 两个方向的提问 |
| 🎭 视角切换 | 观点采择 | 随机角色（5岁小孩/竞争对手/100年后的人…） |
| 🧩 SCAMPER | 经典创造力技法 | 随机抽取七类问题 |
| 🌱 孵化 | 默认模式网络/孵化效应 | 标记节点，延迟后重新推送到画布顶部并附带随机触发卡 |

抽卡生成的节点带专属颜色/图标，自动与原节点连线并标注类型（如 `关联→`）。

### 4. 孵化卡逻辑（2.2）
- 可选延迟：30 秒（演示）/ 2 小时 / 1 天 / 下次打开应用时
- 打开画布时 `checkIncubation()` 检查到期节点，上移到画布顶部、附带鼓励语与一张随机触发卡

### 5. 发散 / 收敛模式（2.4）
- 顶部开关切换。发散模式自由创作，不做评判
- 收敛模式下：选中节点出现标签选择器（可行性 高/中/低、主题分类）；右侧"收敛看板"按标签分组；支持勾选节点导出为 Markdown

### 6. 语义聚类提示（2.3）
- 点击"整理"按钮，或每新增 5 个节点自动触发
- 相近节点用彩色 outline 高亮，左下角列出聚类组，可点"聚拢"把该组节点吸附成网格（不强制、可忽略）

## 数据结构

见 `src/types.ts`，完全对齐 PRD 第 4 节（`CanvasNode` / `CanvasEdge` / `CanvasProject`），并新增 `schemaVersion` 用于版本迁移。

  lib/clustering.ts       # TF-IDF 语义聚类
  lib/utils.ts
  store/canvasStore.ts    # Zustand，所有画布逻辑
  components/
    TextNode.tsx          # react-flow 自定义节点
    TriggerPanel.tsx      # 认知触发器面板
    TagEditor.tsx         # 收敛标签编辑
    ConvergeBoard.tsx     # 收敛看板 + 导出
  pages/
    HomePage.tsx          # 画布列表 + 工作流总览
    CanvasPage.tsx        # 画布主页面
    WorkflowPage.tsx      # 创意工作流呈现页
```
